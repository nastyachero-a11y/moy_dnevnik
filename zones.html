Карта зон влияния

Заполни таблицы — потом построим твой маршрут

1
Могу изменить действием
Ситуация, которая волнует Действие, которым её можно решить Какие ресурсы для этого нужны
2
Могу повлиять через других
Ситуация, которая волнует Ресурс / человек, которого можно привлечь Какие ресурсы для этого нужны
3
Могу только принять
Ситуация, которая волнует Есть ли теоретическое решение? Можешь ли ты на это повлиять хотя бы как-то?
Сохранено ✓
✦ Твои маршруты построены
Три отдельных пути — по одной зоне влияния
Важно: Если в категории «Могу только принять» хотя бы на один вопрос ответ «нет» — нет причин дальше размышлять об этой ситуации и накручивать себя.
